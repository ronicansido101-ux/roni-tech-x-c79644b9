# Security Policy

## Reporting a Security Issue

If you discover a security problem in RONI TECH X, please report it privately.

Please include:

- Description of the issue
- Steps to reproduce
- Affected feature or page
- Any useful screenshots or details

## Important

Please do not publish security issues publicly before they are reviewed.

We appreciate responsible reports and will work to improve the security of RONI TECH X.
