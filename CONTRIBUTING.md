# Contributing to RONI TECH X

Thank you for your interest in improving RONI TECH X! 🚀

## How to contribute

1. Check existing Issues before creating a new one.
2. Describe your idea or problem clearly.
3. Include device information if your issue is technical.
4. Provide screenshots when possible.

## Suggestions

You can suggest:

- New repair guides
- New tools
- New supported devices
- Website improvements
- AI assistant improvements

## Bug Reports

When reporting a bug, include:

- What happened?
- What device/system are you using?
- Steps to reproduce the problem.
- Expected result.

Thank you for helping improve RONI TECH X 💙
